# work-task-manager-legal

Public hosting for the **Tasktician** iOS app's privacy and support pages, served
via GitHub Pages. This repo intentionally contains **no app source** — that lives
in a separate repository (`work-task-manager`).

Live (the account's user-site custom domain serves project sites here, not
`github.io`):

- **Privacy Policy:** https://www.madsvschristensen.dk/work-task-manager-legal/
- **Support:** https://www.madsvschristensen.dk/work-task-manager-legal/support.html

`index.html` is the published source of truth for the privacy policy. The pages
are self-contained static HTML with no third-party dependencies, trackers, or
analytics — consistent with the app's privacy stance.
